# DaveDHD
It should come as no surprise to strangers on the internet that I have ADHD. This is a site to help manage that.

The plan is to start very simply. First, I want somewhere where I can dump any excess thoughts I'm having so I can deal with them later. Then, I would like to build it out into a to-do manager where I can plan both repetitive and one-off tasks. I've had a lot of ideas about it, but I won't get into all of that here. 

One day we might even have fidget spinners. 

## Tech stack
The backend is rust because I think rust is cool. The frontend is react because I've done a fair bit of it and I'm less fussed about the frontend.
